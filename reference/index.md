# Package index

## All functions

- [`andes`](https://gaballench.github.io/tbea/reference/andes.md) :
  Divergence-time estimation data for cis-trans-Andean pairs
- [`c_truncauchy()`](https://gaballench.github.io/tbea/reference/c_truncauchy.md)

- [`concatNexus()`](https://gaballench.github.io/tbea/reference/concatNexus.md)

  : conflate: Calculate the conflation of multiple distributions pdfs,
  plot = TRUE, from, to, n, add = FALSE
- [`crossplot()`](https://gaballench.github.io/tbea/reference/crossplot.md)
  : crossplot: Plot the mean/median and HPD interval bars for pairs of
  distributions
- [`cynodontidae.posterior`](https://gaballench.github.io/tbea/reference/cynodontidae.posterior.md)

  : Prior samples for the family Cynodontidae

  Geochronology samples from the Honda Group in Colombia

  : Constructing a curve for the user-specified lognormal prior using
  Beast2 parameters
- [`measureSimil()`](https://gaballench.github.io/tbea/reference/measureSimil.md)
  : Calculate the Intersection Between Two Densities

  : Reduced chi-square test or mean square weighted deviation (mswd)

- [`quantile_conflation()`](https://gaballench.github.io/tbea/reference/quantile_conflation.md)
  : quantile_conflation: Calculate the quantile for a given probabiliy

- [`stratCI()`](https://gaballench.github.io/tbea/reference/stratCI.md)
  : stratCI: Estimate the confidence intervals of endpoints in

  : summaryBrlen: Summarise branch lengths on trees with identical

- [`table2nexus()`](https://gaballench.github.io/tbea/reference/table2nexus.md)
  : table2nexus: Read a data matrix in delimited format and convert into

- [`tnt2newick()`](https://gaballench.github.io/tbea/reference/tnt2newick.md)
  : tnt2newick: Function for converting from TNT tree format to newick

- [`topoFreq()`](https://gaballench.github.io/tbea/reference/topoFreq.md)
  : Frequency of topologies in a tree sample
- [`xintercept()`](https://gaballench.github.io/tbea/reference/xintercept.md)
  : xintercept: Estimate the x-intercept of an empirical cdf
